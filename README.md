# 探栏

中文名：**探栏** · 前缀 `probe` · 端口 **8100**

## 骨架（新骨）

**传感报文装载 → 标定/质控门槛入栏 → 站点汇总物化 → 坏点旁路 → 栏账互证**

| 对比 | 潮切 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 事件时入窗→关窗 | 双轨对齐 | **质控门槛入栏→站点汇总** |
| 在途 | 入窗缓冲 | 悬账 | **入栏缓冲（过门槛未汇总）** |
| 产物 | 窗切片 | 对齐差+结论 | **站点汇总账** |
| 旁路 | 迟到匣 | 悬账缺边 | **坏点匣（未过门槛）** |

皮：环境监测传感站（大气/水质探头）。去皮：**标定质控门槛 + 入栏 + 汇总物化 + 坏点旁路 + 栏贯验**。  
禁止做成运维工单、告警大屏、传感器 CRUD。禁止抄潮切窗号/对拍左右轨命名。

## 报文键幂等修复（probe-bug-03）

- 落点形态：**切流账册**。`幂等账册` 以业务报文号（`报文编号`）为主键原子占坑（`INSERT OR IGNORE`），展示流水号降级为非唯一留存列，拒绝展示号回刷。
- 连接层开 WAL + `busy_timeout=5000`，双会话同展示号异业务号并发不再互吞；同业务号并发只一笔赢，另一笔合法幂等驳回。
- 新增 `GET /api/对账/报文流`：账册占坑与现行（观测报文/入栏缓冲/坏点匣）对账，吞票/悬空/回刷/无占坑一律报红，杜绝假绿。
- 幂等键源在五页可见：探栏台、报文流、入栏缓冲、坏点匣、幂等键源（策略页）。
- 旧库平滑迁移：自动补展示号列并按业务号回填账册。
- 测试：`backend/tests/test_idemkey_x.py`（同展示号异业务号现行两行）、`test_idemkey_y.py`（对账假绿/页面键源）、`test_idemkey_z.py`（并发争用/WAL）。
